# 饮片炮制记录台

一条记录是一整包炮制文书，里面是工序数组，不是拆成多列指标的普通表单。清炒温度和时长不在范围内就不能放行。

开炒前须先预约**留样条码**：炮制员为饮片生成条码串并预约取样窗口起止时刻。写入记录时必须挂一个条码，写入时刻落在窗口内且条码未作废、未使用才放行；成功写入后条码标记已使用，不可复用。条码作废会进作废流水。

## 留样条码规则

- 炮制员在「留样条码」页**预约生成**条码：指定饮片与取样窗口起止时刻，系统生成全局唯一条码串（`LY日期-随机串`）。
- 写入炮制记录时须挂条码，服务端逐条校验，任一不满足即**拒写**：
  - 条码存在；
  - 写入时刻在预约窗口 `[起, 止]` 内；
  - 条码未作废；
  - 条码绑定的饮片与记录饮片一致；
  - 条码未被使用（一笔记录用完即标记 `used`，不可复用）。
- 炮制员可将有效条码**作废**，作废动作单独成单（条码 + 原因），并写入**作废流水**；已使用的不可作废。
- 质检员可查阅预约条码与作废流水，但不能生成、不能作废、不能写入记录。
- 页内分「预约生成」「有效条码列表」「作废流水」三个独立区块，作废操作不塞进列表行。

## 验收

1. processor 登录后，甘草为放行，黄芩为未放行（温度过低）。
2. 再写一条温度 200 的清炒，结论仍是未放行。
3. checker 看不到写入按钮。
4. processor 在「留样条码」页为白芍预约一个**窗口覆盖现在**的条码。
5. 挂该条码写入一笔 88℃、9 分钟的清炒，应成功（放行），条码随即标记已使用。
6. 仍用同一条码再写第二笔，应失败（条码已使用，不可复用）。
7. 窗口外、饮片不一致、条码不存在或已作废，写入均应被拒；作废条码进作废流水且不可再写入。
8. checker 在「留样条码」页只能查看预约与作废流水，看不到预约生成与作废入口。
